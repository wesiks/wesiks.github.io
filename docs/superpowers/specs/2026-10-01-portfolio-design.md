# Сайт-портфолио wesiks — дизайн-спека

Дата: 2026-10-01 · Статус: согласовано с пользователем (дизайн предложен, вопросы по контенту пропущены — приняты дефолты)

## Цель

Персональный сайт-портфолио разработчика **wesiks** (github.com/wesiks): показать 4 проекта, стек, дать связь. Настроение по запросу пользователя: «депрессивное, больше воздуха» — тихий, тёмный, меланхоличный, просторный. Термин impeccable для такого сайта: режим **Experience** — работа говорит сама, интерфейс отступает.

## Решения (defaults, все легко меняются)

- Имя на сайте: ник **wesiks** (настоящее имя не указано)
- Контакты: **только GitHub** (email/telegram добавляются одним блоком в HTML)
- Проекты: все 4 репозитория отдельными карточками
- Языки: **RU (по умолчанию) + EN**, переключатель без перезагрузки, выбор запоминается в localStorage
- Стек: чистый HTML/CSS/JS, без сборки; шрифты Google Fonts (Inter + Instrument Serif)

## Структура (one-page, длинный скролл)

1. **Hero** — мелкая надпись «портфолио», ник крупно курсивным serif, строка-тэглайн: «Пишу для себя — а значит, честно» / “Built for myself — which means honestly”
2. **Проекты (01–04)** — VoiceTyping (Python), Caser.One Helper (C#), Case Battle Helper (C#), Musor Drop Helper (C#): название, описание, стек, год, ссылка на репозиторий
3. **Обо мне / стек** — Python, C#, десктоп, автоматизация; «инструменты, которые живут в трее и не мешают»
4. **Контакты** — GitHub; финальная строка «сделано в тишине / made in silence»

## Визуальный мир

- Палитра: фон #0E0F12 (почти чёрный, синевато-серый), поверхность #14161B, текст #A6A9B0 (туман), приглушённый #5E626B, акцент #94A3BD (выцветший сине-серый), волосяные линии rgba(166,169,176,.14)
- Типографика: Instrument Serif italic для имени и акцентов, Inter Light/Regular для текста; мелкие лейблы — uppercase, letter-spacing 0.18em
- Воздух: секции минимум 80vh, контент-колонка 680px, отступы крупнее «комфортных»
- Атмосфера: плёночное зерно (SVG noise, 3%), медленные проявления из blur (1.1s, stagger), ничего не дёргается, hover — подсветка и сдвиг волосяной линии, не более
- Нумерация 01–04 и угловые метки — журнальность

## Техника

- `index.html` / `styles.css` / `main.js` в корне проекта
- i18n: `data-ru` / `data-en` атрибуты; JS подменяет текст, меняет `html lang`, хранит выбор; без JS сайт полностью читаем на RU
- Анимации: CSS + IntersectionObserver, `prefers-reduced-motion` уважается
- Адаптив: 360px → 1440px+, мобильная типографика отдельные clamp-правила
- Доступность: контраст ≥ 4.5:1 для текста, фокус-стили,语义 HTML, aria-метки переключателя языка
- SEO/мета: title, description, Open Graph, favicon (SVG «w.»)
- Деплой: GitHub Pages (позже, отдельным шагом)
